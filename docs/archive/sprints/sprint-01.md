# Sprint 01: Client & Project Management

## Goal
Deliver core client and project management capabilities.

## Scope
- Clients
- Projects

## API Endpoints
- `POST /clients`
- `GET /clients`
- `GET /clients/{client_id}`
- `PUT /clients/{client_id}`
- `DELETE /clients/{client_id}`
- `POST /projects`
- `GET /projects`
- `GET /projects/{project_id}`
- `PUT /projects/{project_id}`
- `DELETE /projects/{project_id}`

## Database Tables
- `clients`
- `projects`

## Success Criteria
- Able to create, read, update, and delete clients.
- Able to create, read, update, and delete projects.
- Projects link to clients and preserve data integrity.
