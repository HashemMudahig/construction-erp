## 1. Conventions

- Primary keys: `UUID` generated by `gen_random_uuid()` (requires `pgcrypto`).
- Money: `NUMERIC(14,2)` — never `FLOAT`/`REAL`.
- Timestamps: `TIMESTAMP WITH TIME ZONE`, stored UTC (`created_at`, `updated_at`).
- Status: native `enum` for project lifecycle.
- All tables live in the `public` schema.

## 2. DDL

```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TYPE project_status AS ENUM
  ('planning','active','completed','on_hold','cancelled');

CREATE TABLE users (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name          VARCHAR(120)  NOT NULL,
  email         VARCHAR(255)  NOT NULL UNIQUE,
  password_hash VARCHAR(255)  NOT NULL,
  role          VARCHAR(20)   NOT NULL DEFAULT 'admin',
  created_at    TIMESTAMPTZ   NOT NULL DEFAULT now()
);

CREATE TABLE clients (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name       VARCHAR(200) NOT NULL,
  phone      VARCHAR(40),
  email      VARCHAR(255),
  address    VARCHAR(500),
  notes      TEXT,
  archived   BOOLEAN      NOT NULL DEFAULT false,
  created_at TIMESTAMPTZ  NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ  NOT NULL DEFAULT now()
);
CREATE INDEX idx_clients_name_lower ON clients (lower(name));

CREATE TABLE projects (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  client_id   UUID          NOT NULL,
  name        VARCHAR(200)  NOT NULL,
  description TEXT,
  budget      NUMERIC(14,2) NOT NULL CHECK (budget >= 0),
  start_date  DATE,
  end_date    DATE,
  status      project_status NOT NULL DEFAULT 'planning',
  created_at  TIMESTAMPTZ   NOT NULL DEFAULT now(),
  CONSTRAINT fk_projects_client
    FOREIGN KEY (client_id) REFERENCES clients(id) ON DELETE RESTRICT,
  CONSTRAINT chk_projects_dates
    CHECK (end_date IS NULL OR start_date IS NULL OR end_date >= start_date)
);
CREATE INDEX idx_projects_client_id ON projects (client_id);
CREATE INDEX idx_projects_status     ON projects (status);
```

## 4. Constraints & Indexes

- PK: `users.id`, `clients.id`, `projects.id`.
- Unique: `users.email`.
- FK: `projects.client_id` → `clients.id` `ON DELETE RESTRICT`.
- Check: `projects.budget >= 0`; `end_date >= start_date`.
- Index: `idx_clients_name_lower`, `idx_projects_client_id`, `idx_projects_status`.

## 5. updated_at Trigger

```sql
CREATE OR REPLACE FUNCTION set_updated_at() RETURNS TRIGGER AS $$
BEGIN NEW.updated_at = now(); RETURN NEW; END; $$ LANGUAGE plpgsql;

CREATE TRIGGER trg_clients_updated_at
BEFORE UPDATE ON clients
FOR EACH ROW EXECUTE FUNCTION set_updated_at();
```

## 6. Alembic Migration Plan

Revision `0001_initial`:

1. `op.execute("CREATE EXTENSION IF NOT EXISTS pgcrypto")`.
2. Create `project_status` enum via `sa.Enum(..., name='project_status')`.
3. Create `users`, `clients`, `projects` with all columns/constraints.
4. Create indexes.
5. Create `updated_at` function + trigger via `op.execute`.

Downgrade reverses in opposite order (drop trigger/function, indexes, tables, enum, extension).

```bash
alembic revision --autogenerate -m "initial users clients projects"
alembic upgrade head
```
