# Sprint 03: Dashboard Overview

## Goal
Deliver dashboard functionality for project and financial overview.

## Scope
- Dashboard

## API Endpoints
- `GET /dashboard/summary`
- `GET /dashboard/projects`
- `GET /dashboard/finance`

## Database Tables
- `clients`
- `projects`
- `payments`
- `expenses`

## Success Criteria
- Dashboard endpoint returns key project metrics and cash flow summary.
- Frontend can render project health and financial snapshot.
- Data aggregation is accurate across projects, payments, and expenses.
