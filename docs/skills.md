# Required Skills

## FastAPI
- Description: Modern Python web framework that supports async endpoints and automatic OpenAPI documentation.
- Why needed: Provides the API layer for all backend features and enables rapid development with strong validation.

## PostgreSQL
- Description: Open-source relational database with ACID compliance and advanced query capabilities.
- Why needed: Stores ERP data reliably for clients, projects, payments, expenses, and reports.

## SQLAlchemy
- Description: Python ORM and SQL toolkit that maps Python classes to database tables.
- Why needed: Models the database layer cleanly and manages object-relational persistence.

## Flutter
- Description: UI toolkit for building native-like apps from a single codebase.
- Why needed: Delivers a responsive, native-feeling front-end for ERP users on mobile and desktop.

## Riverpod
- Description: Reactive state management library for Flutter with compile-safe providers.
- Why needed: Manages feature state and backend communication cleanly across the app.

## Clean Architecture
- Description: Architectural pattern separating presentation, domain, data, and infrastructure concerns.
- Why needed: Keeps the ERP codebase maintainable, testable, and scalable.

## REST APIs
- Description: Standard protocol for client-server communication using HTTP verbs and JSON payloads.
- Why needed: Connects the Flutter frontend with the FastAPI backend in a predictable way.

## Docker Basics
- Description: Containerization technology for packaging applications and services.
- Why needed: Simplifies development and deployment with isolated backend, frontend, and database containers.
